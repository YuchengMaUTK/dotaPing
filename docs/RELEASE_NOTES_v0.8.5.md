# DotaPing 0.8.5 — macOS source preview

Dota-style pings for the Mac desktop, with an Option-click/drag signal wheel,
nine ping types, desktop animation, sound control and a ⌘⌥P fallback.

- Native Swift/AppKit menu-bar app, targeting macOS 13+.
- Apple Silicon is the currently validated architecture.
- Original map-inspired application and menu-bar icons.
- Source provenance manifests, standalone core checks and macOS CI included.

This is a source preview. Valve resources are not included. Supply assets you are
entitled to use and follow the README to build locally. No public binary is attached.
Local builds use ad-hoc signing and are not notarized.

Physical multiple displays, fullscreen behavior, VoiceOver, macOS 13 runtime
compatibility and real cross-app gestures require further manual validation.
This unofficial project is not affiliated with Valve.
